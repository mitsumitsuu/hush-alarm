# HUSH Alarm 0.1.0 — 検証結果

2026年10月15日（日本時間）

## 確認済み

- Windows 11: .NET FrameworkのC#コンパイラで実行ファイルを生成。
- Windowsロジックテスト15件成功。日付またぎ、同時刻は翌日、具体的な機器ID必須、スピーカー分類の拒否、予定時刻、二重鳴動防止、鳴動前／中の切断、再接続で自動再開しないこと、タイマーの時計変更耐性、取り逃した時刻の無音停止、手動停止。
- Windows統合テスト8件成功。実OSでの機器一覧取得、既定出力・存在しないID・既定スピーカー指定の拒否、暗号化されたPIN認証、誤PIN拒否、試行回数制限、PINの平文非保存。接続された対応イヤホンは0台だったため、実音は再生していません。
- Windows画面の描画を画像で確認。
- iPhone: 7件のSwiftテスト成功。時間指定、タイマーの単調時計、日付またぎ、同時刻、無効入力、スピーカー等の拒否、登録UIDの一致。
- iPhone: XcodeでiOS端末向けReleaseビルド成功。arm64実行ファイル、Info.plist検証、Payload構成のIPA生成成功。
- [iPhoneビルド実行結果](https://github.com/mitsumitsuu/hush-alarm/actions/runs/38669416049)
- 音は両端末でローカル生成。アプリ本体にはHTTP通信、広告SDK、解析、クラウド保存、課金処理なし。

## 実機未確認

- 実イヤホンからの再生と、本体スピーカーに音が出ないこと。
- Bluetooth切断の瞬間・電池切れ・接続先変更時の実際の音の出方。
- iPhoneへの署名／インストール、端末認証画面、画面ロック中、通信オフ、長時間、省電力、通話中の動作。
- Windowsの実イヤホン再生、ふたを閉じた場合や手動スリープなど。

コーディング上の安全停止と、物理的に音漏れがないことは別です。「使い方」の自宅テスト後に利用してください。今回の版は実機テスト用の先行版です。
