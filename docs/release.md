# HUSH Alarm 0.1.0

広告・課金・常時通信なしの、イヤホン専用アラームです。

- Windows版: ZIPを展開し、HushAlarm.exeを起動。
- iPhone版: 未署名IPAです。AltStore Classicなどで本人のAppleアカウントによる署名が必要です。無料アカウントでは7日以内ごとに更新してください。iOS 17以降。
- 時刻指定、仮眠タイマー、3種類の音、徐々に音量が上がる再生、停止、3分スヌーズ。
- 接続先変更や割り込みで停止。スピーカー再生・音付き通知による代替はありません。

**実イヤホンの切断時、iPhoneロック中・通信オフ・長時間の動作は実機未検証です。最初に自宅で確認してから使ってください。**

詳しい導入と確認: リポジトリの docs/使い方.md。
