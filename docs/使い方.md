# HUSH Alarm

WindowsとiPhoneで使う、広告・課金なしのイヤホン専用アラームです。両端末のアラームは独立しています。設定の同期はありません。

## Windows

1. Windows版ZIPを展開し、`HushAlarm.exe`をダブルクリック。
2. 初回だけ6〜12桁のPINを作成。次回からそのPINでログイン。
3. イヤホンを接続し、出力先を選ぶ。表示されなければ「更新」。
4. 「時刻指定」か「仮眠タイマー」を選び、「セットする」。
5. 起きたら「停止」。鳴動中は「3分後に再通知」も使用可能。

インストール、管理者権限、追加ランタイムのダウンロードは通常不要です。Windows 11の.NET Frameworkを使います。自己署名も購入もしていないためWindowsが提供元を未確認と表示する場合があります。アプリ起動中の通常の自動スリープは抑止しますが、PCの電源オフ・手動スリープ・ふたを閉じた状態には対応しません。アプリを終了するとアラームも停止します。

Windowsがイヤホン／ヘッドセットと報告する機器だけを一覧に表示します。スピーカーや不明な機器として認識されるイヤホンは、安全のため使用できません。接続先を固定し、既定のスピーカーへの代替再生はしません。

PINの照合情報はWindowsユーザー単位で暗号化して端末に保存します。PINは外部送信せず、平文保存もしません。PINを忘れた場合は自動復旧しません。認証情報の削除が必要になるため、別途相談してください。

## iPhone（初回だけPCで導入）

必要: Windows PC、iOS 17以降のiPhone、USBケーブル、本人のAppleアカウント。Appleへのログインや2段階認証は本人が行います。パスワードをチャットに送らないでください。

1. [AltStore ClassicのWindows向け公式手順](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows)に従い、AltServerと必要なApple製ソフトをPCへ入れる。既存のソフトの削除が必要と案内された場合は、削除せずそこで相談する。
2. iPhoneをUSB接続し、信頼・Wi-Fi同期を設定。AltServerからAltStoreを導入し、本人がAppleにログインする。iPhoneで求められた開発者モード／信頼を設定する。
3. `HUSH-Alarm-iPhone-unsigned.ipa`をiPhoneへ渡す。AltStoreの「My Apps」の「＋」で選び、インストールする。
4. HUSH Alarmを起動し、Face ID／Touch ID／iPhoneのパスコードでログイン。
5. イヤホンを接続し、「イヤホンを登録」。表示された機器がイヤホンであることを確認する。Bluetoothスピーカーは登録しない。
6. 時刻か仮眠時間を選び、「セットする」。画面はロックできる設計ですが、アプリを上へスワイプして完全終了しない。

**7日以内ごとの更新:** PCでAltServerを起動し、iPhoneとPCを同じWi-Fiに接続して、AltStoreの「My Apps → Refresh All」。USB接続でも更新できる。AltServerの自動更新だけに任せず、AltStoreで残り日数を確認する。期限切れのままではアプリを起動できません。既存のサイドロードアプリがある場合、無料アカウントの台数・アプリ数の制限にも注意してください。[Appleの無料署名の説明](https://developer.apple.com/help/account/basics/about-your-developer-account)

## 音と通信

- 音は端末内で生成。アラーム使用時にネット接続は不要です。広告・外部API・解析・サーバーへの記録はありません。
- ダウンロード、ビルド、Appleでの署名更新には通信が必要です。最初のダウンロードと更新はWi-Fiを推奨。
- 音量は初期25%、上限50%。端末本体のメディア音量にも影響されます。システム音量を勝手に上げません。
- iPhoneでは待機中も音声処理を続けるため電池を使います。イヤホンとiPhone両方の残量を確保する。
- イヤホン切断、接続先変更、通話などの割り込みで停止し、再接続だけでは鳴り直しません。改めてセットする。
- イヤホンが使えない場合は無音で停止します。振動による起床は保証しません。スピーカーや音付き通知への切り替えはありません。
- 鳴動は最大10分。止め忘れによる無期限の再生を避けます。

## 最初に自宅で確認

実機の音の出方は開発環境から確認できないため、以下を通してから通学などに使用してください。アプリ内の試聴は徐々に音量が上がり、短時間で停止します。

1. イヤホンを接続して「試聴」。イヤホンだけに聞こえ、本体スピーカーからは聞こえないことを確認。
2. 1分タイマーを設定し、画面ロック。時刻どおり鳴るか確認。
3. 1分タイマーの待機中にBluetoothを切る。予定時刻になっても本体から音が出ないことを確認。
4. 鳴っている途中でBluetoothを切る。本体から音が出ないことを確認。再接続だけでは再開しないことも確認。
5. Wi-Fi・モバイル通信を切り、Bluetoothのみオンで同じテストを行う。
6. 普段使う長さ（20〜60分など）、省電力モード、音楽再生中でも確認。通話などで停止する場合は、その状態では使わない。

## 確認済みと未確認

- Windows: コンパイル、15件の時刻・安全停止ロジックテスト、8件の実OS機器一覧・認証テスト、画面の描画を確認。音は再生していません。
- iPhone: macOSのGitHub Actionsで端末用ビルドと7件のコアロジックテストが成功。未署名IPAを生成しました。
- 未確認: 実イヤホンでの音漏れ、切断の瞬間、iPhoneでの署名・インストール・ロック中・長時間・省電力・通話との組み合わせ。ソースに切断停止処理があることと、実機で音漏れが起きないことは別です。

## 開発を再開する場合

ソースZIPまたはGitリポジトリを使用。Windowsビルドは `scripts/build-windows.ps1`、iPhoneビルドはGitHubの「Build iPhone app」。公開リポジトリの標準macOS実行環境を使い、署名用の秘密は登録しません。大きい有料実行環境、有料Apple契約、課金サービスは使用しません。
